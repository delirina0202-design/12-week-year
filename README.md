# Мой 12-недельный год

Трекер целей по системе «12 недель в году» (Брайан Моран). React + Vite + Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev
```

## Деплой на Vercel

Готового «подключения» из чата к вашему аккаунту Vercel нет — привязанный к этому чату
Vercel-коннектор умеет только просматривать существующие проекты и деплои, но не может
создавать новые. Поэтому задеплоить нужно одним из двух стандартных способов:

### Вариант A — через CLI (самый быстрый, без GitHub)

1. Распакуйте архив и откройте папку в терминале.
2. Установите зависимости: `npm install`.
3. Выполните: `npx vercel` — CLI попросит войти в аккаунт Vercel (через браузер) и
   задаст пару вопросов о проекте (можно везде оставить значения по умолчанию).
4. Для продакшен-деплоя: `npx vercel --prod`.

Vercel сам определит, что это Vite-проект, и настроит команду сборки (`npm run build`)
и папку вывода (`dist`) автоматически.

### Вариант B — через GitHub + дашборд Vercel

1. Создайте новый репозиторий на GitHub и запушьте туда содержимое этой папки.
2. На vercel.com нажмите **Add New → Project**, выберите этот репозиторий.
3. Framework Preset определится как **Vite** автоматически — просто нажмите **Deploy**.

После первого деплоя каждый `git push` в основную ветку будет обновлять сайт
автоматически.
